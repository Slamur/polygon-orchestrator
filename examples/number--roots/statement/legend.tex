Дано натуральное число $N$. Требуется найти целую часть (округление вниз) его кубического корня и целую часть (округление вниз) его квадратного корня.

Более формально, нужно найти:

\begin{itemize}
\item наибольшее целое число $C$, для которого $C^3 \le N$ --- целая часть кубического корня из $N$;
\item наибольшее целое число $S$, для которого $S^2 \le N$ --- целая часть квадратного корня из $N$.
\end{itemize}

Гарантируется, что для заданного $N$ оба числа $C$ и $S$ существуют и определены однозначно.
