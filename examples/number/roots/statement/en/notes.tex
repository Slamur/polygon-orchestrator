\textbf{Example 1.} With $N = 27$: $3^3 = 27 \le 27 < 64 = 4^3$, so the integer part of the cube root is $3$. Also $5^2 = 25 \le 27 < 36 = 6^2$, so the integer part of the square root, rounded down, is $5$. The answer is \texttt{3 5}.

\textbf{Example 2.} With $N = 63$: $3^3 = 27 \le 63 < 64 = 4^3$, so the integer part of the cube root is $3$. Also $7^2 = 49 \le 63 < 64 = 8^2$, so the integer part of the square root is $7$. The answer is \texttt{3 7}. The number $63$ is one less than an exact power ($64 = 4^3 = 8^2$), so both roots rounded down give values one less than the corresponding bases $4$ and $8$.
