The first line contains one integer $N$ $(2 \le N \le 3 \cdot 10^5)$ --- the number of vertices of the tree.

The second line contains $N$ integers separated by spaces $p_1, p_2, \ldots, p_N$ $(0 \le p_i \le N)$ --- the array of parents, where $p_i$ is the number of the parent vertex of vertex $i$, and $p_i = 0$ if vertex $i$ is the root of the tree.

It is guaranteed that:

\begin{itemize}

\item exactly one of the numbers $p_i$ equals $0$;

\item the array of parents defines a correct tree.

\end{itemize}

The vertices of the tree are numbered from $1$ to $N$.
