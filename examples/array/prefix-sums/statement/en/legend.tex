You are given an array of non-negative integers and a number $K$.

Find the shortest prefix of the array whose sum of elements is strictly greater than $K$.

More formally, number the elements of the array from $1$ to $N$ and consider the prefix sums $A_1$, $A_1 + A_2$, $A_1 + A_2 + A_3$, \ldots, $A_1 + A_2 + \ldots + A_N$. Find the minimal index $i$ $(1 \le i \le N)$ such that $A_1 + A_2 + \ldots + A_i > K$. If there is no such index (that is, the sum of the whole array does not exceed $K$), report this separately.
