In the first example, consider the sums of all prefixes of the array:

\begin{itemize}
\item $A_1 = 2 \le K$
\item $A_1 + A_2 = 3 \le K$
\item $A_1 + A_2 + A_3 = 6 \le K$
\item $A_1 + A_2 + A_3 + A_4 = 11 > K$
\item $A_1 + A_2 + A_3 + A_4 + A_5 = 15 > K$
\end{itemize}

The first index $i$ for which the sum $A_1 + A_2 + \ldots + A_i > K$ is $4$. So the answer is ``YES'' and $4$.

In the second example, the sum of the whole array is $2 + 0 + 7 = 9$, which does not exceed $K = 10$. So the required index does not exist, and the answer is ``NO''.
