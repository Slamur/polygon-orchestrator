В первом примере рассмотрим суммы на всех префиксах массива:

\begin{itemize}
\item $A_1 = 2 \le K$
\item $A_1 + A_2 = 3 \le K$
\item $A_1 + A_2 + A_3 = 6 \le K$
\item $A_1 + A_2 + A_3 + A_4 = 11 > K$
\item $A_1 + A_2 + A_3 + A_4 + A_5 = 15 > K$
\end{itemize}

Первый индекс $i$, для которого сумма $A_1 + A_2 + \ldots + A_i > K$, равен $4$. Поэтому ответ: <<YES>> и $4$.

Во втором примере сумма всего массива равна $2 + 0 + 7 = 9$, что не превосходит $K = 10$. Значит, искомого индекса не существует, и ответ --- <<NO>>.
