You are given an array of length $N$, initially filled with zeros. The elements of the array are numbered from $1$ to $N$.

$Q$ operations are applied to the array one after another. The $i$-th operation is given by a triple of numbers $L_i$, $R_i$, $D_i$ and adds the number $D_i$ to all elements of the array with indices from $L_i$ to $R_i$ inclusive.

Print the array after applying all $Q$ operations in order, from the first to the last.
