The first line contains two integers $N$ and $Q$ $(1 \le N, Q \le 3 \cdot 10^5)$ --- the length of the array and the number of operations.

The second line contains $Q$ integers $L_1, L_2, \ldots, L_Q$ $(1 \le L_i \le N)$ --- the left bounds of the operations' segments.

The third line contains $Q$ integers $R_1, R_2, \ldots, R_Q$ $(L_i \le R_i \le N)$ --- the right bounds of the operations' segments.

The fourth line contains $Q$ integers $D_1, D_2, \ldots, D_Q$ $(|D_i| \le 10^9)$ --- the numbers added by the operations: the $i$-th operation adds $D_i$ to each element of the array with indices from $L_i$ to $R_i$ inclusive.
